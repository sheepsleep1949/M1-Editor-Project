M2 规则试玩任务与交接

前期成果与规则语义

你负责唯一规则引擎、玩家体验和服务端选择执行。前期已实现纯函数和独立预期测试，下一步把它接到固定版本与服务端会话。共同基线为《00 共同接口与交接规范》。机器可读契约在 packages/contracts/openapi.json；同名字段与错误码不得各自改写。

已交付给你的文件

packages/engine/src/index.ts；packages/contracts/src/index.ts 与 ports.ts；fixtures/expected/rules.expected.json；tests/engine.test.ts；选择请求和响应见 fixtures/api/execute-choice.*.json。

规则明确行为
条件conditions 全部满足才允许；空数组总允许；只读取操作前的布尔值
效果effects 赋值后进入目标；同一变量不重复赋值；只输出真正变化的 delta
状态包含 nodeId 和全部变量；不存在或多出的变量状态拒绝
道具道具只是 kind=item 的布尔变量；获得设 true，消耗设 false
结局kind=ending 后 getChoices=[]，执行返回 AT_ENDING
历史影响后续的历史必须存为 flag；不得用 UI 点击次数隐式决定

初始直接 c_enter 返回 CONDITION_NOT_MET；初始 c_find 返回 CHOICE_NOT_FOUND；取得钥匙后再搜索被拒绝；c_quit 到合法退出结局。第二故事使用完全不同的节点和变量，已有测试验证同一实现可运行。

引擎不接收活动名称判断、不访问 DB、不读取时钟、不产生随机数。选项是否开放必须来自同一规则实现；前端禁用按钮不能代替服务端校验。

执行接口与事务交接

POST /api/v1/versions/{versionId}/sessions
body: {requestId, shareWithCreator}
GET  /api/v1/sessions/{sessionId}
POST /api/v1/sessions/{sessionId}/choices
body: {choiceId, expectedSeq, requestId}

创建试玩返回 Session，seq=0，初始状态来自版本配置，playerId 来自登录。选择响应包含 sessionId、versionId、seq、state、choices、eventId、status。禁止接受客户端提供的“执行后状态”；服务端只接受选择意图。

事务中的固定顺序

鉴权并确认归属 → 按请求 ID 查同次操作回执 → 比较请求摘要 → 验证 expectedSeq → 读取固定版本与状态 → applyChoice → 按旧 seq 条件更新会话 → appendEvent(tx,...) → 提交。回执命中时返回原响应，不能先因旧 seq 拒绝正常重试。

M4 提供 DbTx 与 withTx。你持有事务边界，向 M5 交付 before/after/delta、choiceId、序号和响应；M5 的函数必须使用同一个 tx。状态更新成功而事件写失败时，全部回滚。数据库锁或唯一约束冲突需映射为可处理错误，并只在安全范围内重试整个事务。

你交给别人什么

接收方你的交付共同验收
M3引擎导出、语义、正常与非法选择样例检查器逐步执行的状态与人工预期一致
M5ApplyResult、事件内容、同一 tx 参数一次成功只有一事件；注入写失败整体回滚
M4会话与状态 Schema、读取当前 seq 的约定保存绑定该时刻状态；恢复初始快照可继续执行
M1变量与选项约束、错误码表单能表达所有首版规则，无故事特判

会话 v1 操作量上限建议 500 个成功事件，作为服务端配置项统一管理；达到上限返回 SESSION_LIMIT_REACHED，不能伪装剧情结局。后续扩展长会话时，M2 与 M5 同步增加分页及完整回放读取。

错误必须有稳定结果

引擎已有 INVALID_STORY、INVALID_STATE、UNSUPPORTED_VERSION、AT_ENDING、CHOICE_NOT_FOUND、CONDITION_NOT_MET。HTTP 序号冲突用 409 SEQUENCE_CONFLICT；同键异载荷用 409 IDEMPOTENCY_CONFLICT；条件问题用 422。任何拒绝都不得改变状态或产生成功事件。

本模块门禁

M3 和 M5 同时通过页面与直接接口操作，核对数据库状态和事件。绕过按钮可作弊、重复扣道具、事件与状态不一致、另写一套条件逻辑，任一存在都阻断验收。关键反例至少包含不同 requestId 同 expectedSeq 的并发，以及同 requestId 不同选择。
